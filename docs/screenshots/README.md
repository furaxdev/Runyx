# Runyx — demo screenshots

Generated automatically by [.github/workflows/demo.yml](../../.github/workflows/demo.yml)
against a real `runyx serve`, a real `llama-server` (ggml-org/llama.cpp,
CPU build) and a real small model (Qwen2.5-0.5B-Instruct-GGUF) — nothing is
mocked. Window fixed at 1440×900 (desktop) and 390×844 (phone), animations
disabled for stable captures.

A short video of a full conversation (send → streamed reply) is attached to
the workflow artifact (not on this branch, to keep it light on every run) —
see the repository's Actions tab.
